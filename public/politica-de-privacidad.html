2. Datos que tratamos

CueStarter.com no esta disenada para crear cuentas de usuario ni para mantener una base de datos de visitantes. La app guarda configuraciones y estado de conversacion en el navegador del usuario mediante almacenamiento local (localStorage), para permitir continuidad de uso.

Este proyecto puede procesar datos tecnicos minimos para operar el servicio, como solicitudes HTTP y registros tecnicos propios de infraestructura/hosting.

3. Finalidades

Las finalidades principales son:

  • Operar la app y entregar sus funcionalidades.
  • Mantener seguridad y estabilidad tecnica.
  • Mejorar la experiencia y corregir errores.

4. Comparticion de datos

No vendemos ni alquilamos datos personales de visitantes. Algunos datos tecnicos pueden ser tratados por proveedores de infraestructura en el contexto normal del servicio.

5. Conservacion

No mantenemos una base de datos de perfiles de visitantes. La informacion guardada en localStorage depende del navegador del usuario y puede eliminarse limpiando datos del sitio.

6. Derechos de las personas

Cuando corresponda segun normativa aplicable, puedes solicitar informacion, correccion, eliminacion u oposicion respecto de tratamiento de datos personales, a traves de los canales de contacto publicados en el sitio.

7. Cambios a esta politica

Esta politica puede actualizarse para reflejar cambios operativos o legales. La version vigente sera siempre la publicada en esta pagina.
